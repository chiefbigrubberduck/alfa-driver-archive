# Alfa Driver Archive
An archive of the earliest drivers for Alfa/Realtek cards, ca. 2000-2014, with Linux, Windows, and Mac versions. Driver's being added. The source is from a purchased Alfa CD with MacOS, Windows and Linux drivers, keep in mind these are the original's and not newer drivers, they are here for posterity. 

> [!NOTE]
> Drivers currently provide a download link, this is temporary, soon the user will be redirected to a wiki page with info and download.
