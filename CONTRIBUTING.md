## Contributing
Welcome! Thanks for contributing. If you want to help, think about working on one of the following things...

- Documentation, research some basic info about one of the cards from the list, maybe find a photo, use that in a wiki, and hyperlink it to the readme.
- Drivers, there are plenty of drivers, but if you have another one, or think you have a better one, let me know, and they will get compared, keep in mind they aren't new ones, older ones.

Once you have your idea, follow the below workflow:
- Open pull request
- Add driver/wiki to pull request
- Ask to merge
- Driver/wiki will be checked
- Will get merged

Please keep in mind that the drivers must be archived ones, archive is the goal here, so if you have older ones, that would be great.
